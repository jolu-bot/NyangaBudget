# 🚀 Guide de Déploiement NyangaBudget 2.0

## 📋 Prérequis

1. Compte GitHub (gratuit)
2. Compte Render.com (gratuit)
3. Git installé sur votre machine

---

## 🔧 Étape 1 : Créer un dépôt GitHub

### 1.1 Créer le dépôt sur GitHub.com

1. Allez sur https://github.com
2. Cliquez sur **"New repository"** (vert en haut à droite)
3. Remplissez :
   - **Repository name** : `NyangaBudget`
   - **Description** : `Application de gestion budgétaire familiale au Cameroun (FCFA)`
   - **Public** ou **Private** (votre choix)
   - ❌ Ne cochez PAS "Initialize with README" (on a déjà les fichiers)
4. Cliquez **"Create repository"**
