## 🔍 Détails Techniques

### Configuration WSGI Générée

```python
# Template auto-généré par deploy_helper.py
import sys, os
from dotenv import load_dotenv

path = '/home/USERNAME/NyangaBudget'
if path not in sys.path:
    sys.path.insert(0, path)

load_dotenv(os.path.join(path, '.env'))

os.environ['VIRTUAL_ENV'] = '/home/USERNAME/.virtualenvs/nyangabudget-env'
activate_this = os.path.join(os.environ['VIRTUAL_ENV'], 'bin/activate_this.py')

with open(activate_this) as f:
    exec(f.read(), {'__file__': activate_this})

from app import app as application
application.config['DEBUG'] = False
```

### Variables d'Environnement Documentées

**Obligatoires** (4) :
- `SECRET_KEY` : Clé Flask unique
- `DATABASE_URL` : URL base données
- `FLASK_ENV` : production
- `FLASK_DEBUG` : 0

**Optionnelles** (23) :
- OCR : `OPENAI_API_KEY`, `TESSERACT_CMD`
- Email : `MAIL_SERVER`, `MAIL_USERNAME`, `MAIL_PASSWORD`
- Cache : `CACHE_TYPE`, `CACHE_REDIS_URL`
- Sécurité : `CSRF_ENABLED`, `RATE_LIMIT`
- Logs : `LOG_LEVEL`, `LOG_FILE`
- Production : `PRODUCTION_URL`, `SENTRY_DSN`
